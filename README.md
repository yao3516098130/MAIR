## 关于「立即可试」交互演示（v4.2 新增）

任务书参考站点（Raycast / Cursor / NotebookLM）的价值主张都建立在**可操作**之上。原页面只有静态截图，访客只能看、不能试。v4.2 补上一个纯前端的交互演示：

- **两种输入方式**：点左侧预置问题，或在底部输入框自己打（回车发送，Shift+回车换行）
- **四个模式可切换**：公共事务 / 知识学习 / PPT 制作 / 算法练习，各有成套的步骤文案与问题库
- **完整还原使用链路**：提问 → 逐步执行步骤（带动画勾选）→ 流式输出回答 → 标注「依据 · 原文出处」→ 生成产物卡（笔记 / 计划 / 复习卡 / PPTX / 代码运行）
- **输入理解**：自己输入的问题会做关键词匹配，命中预置问题就给对应答案，否则按该模式的通用思路给示意回答
- **诚实标注**：输入框下方明确写着这是**静态演示**（结论为预置内容），真实回答由平台检索课程资料与官方文件生成

> ⚠️ 演示内容仅为产品使用方式的示意，**不是真实检索结果**，不构成功能承诺。所有演示文案均为通用示例（请假流程、14 天复习计划、PPT 页结构等），不含真实课程、教师或教务信息。

## 关于「四个入口」的措辞

页面原先写「四个入口」，语义上把公共事务 / 知识学习 / PPT 制作 / 算法练习当成了并列的导航入口；但它们是**功能模式**，不是入口。v4.2 已统一改为**「四个模式」**（首屏价值卡「一个入口」同步改为「一个模式」）。

### 交互演示内容的规格化

演示回答不再是泛泛文案，而是按文档定义的产品输出结构组织：

- **公共事务**：每条回答固定给出「适用对象 / 政策依据」+ 分档步骤 + 「需要再确认的」未知项说明（对应 `AffairsAnswerCard` 的 `applicableTo` / `policyVersion` / `unknowns` / `boundaryNote`）
- **知识学习**：结构化讲解拆为「核心概念 / 一个示例 / 三个易错点 / 延伸学习建议」四段（对应 Course Mentor 的输出结构），末尾明确标注哪些内容原文未展开
- **算法练习**：代码块标题写明运行状态与测试结果，note 里单列「运行证据：语言 · 退出码 · 耗时 · 可见测试通过数」（对应 `ExecutionEvidence`）
- **PPT 制作**：步骤增加「生成逐页方案（目的 / 信息量 / 引用 / 讲稿）」，产物说明改为「每页含讲稿备注 · 已完成页面质量检查」
- **范围澄清**：宽泛提问走澄清卡 → 补充 courseId / materialGroupIds / materialIds → 「继续刚才的任务」续跑（对应 Scope-first RAG 与 `CourseKnowledgeUnit` 定位字段）

### 交互演示的「去伪」与品牌球体还原（v4.4）

用户指出演示区那段自述式步骤文案（「识别为校园事务咨询 / 限定在学生手册 · 培养方案范围 / 检索到 3 处相关条款 / 整理为可执行的材料与流程」）**在真实平台里根本不会显示**，属于编造。同时指出品牌球体应当能**多色混合、持续变色**。

**① 删除假步骤清单，换成真实单行检索提示**

- 四个模式里所有 `steps:[...]` 自述文案全部删除（连同旧的 `.dm-steps` / `.dm-step` 样式与降级动画规则）。
- 改为**忠实复刻真实产品截图**的单行检索状态：
  `◌ 正在理解你的问题并查找相关资料 … 1.6s`
  - 左侧是 CSS 旋转圆环（`.dm-status-spin`，0.7s 线性无限旋转）
  - 右侧是**真实递增**的计时（`setInterval` 每 100ms 刷新，`font-variant-numeric:tabular-nums` 防止数字跳动）
  - 回答开始渲染后，状态行淡出（`.is-out`，260ms）并从 DOM 移除
- 对应到真实平台的语义：这一行就是 RAG 检索的进行中提示，**不含任何未经检索就写死的推理过程**。

**② 品牌球体重做为「多色缓慢流动」（纯 CSS，无图片、无脚本）**

球体从原来的浅灰平面球，改为按用户提供的参考截图还原的**暗底多色网点球**。分层（自下而上）：

| 层 | 作用 | 关键实现 |
|---|---|---|
| ① 深底 | 暗色基底 | `background:#0B0D11` |
| ② 色团 A | 青绿 → 薄荷 → 湖蓝（参考图最亮的一束） | `radial-gradient` + `animation:orbA 17s` |
| ③ 色团 B | 淡紫 → 藕粉 → 玫红（左下那团） | `animation:orbB 21s` |
| ④ 色团 C | 米黄 → 琥珀 → 暖橙（右上那团） | `animation:orbC 25s` |
| ⑤ 冷白高光 | 左上角一小片过曝（**不铺满**，避免洗灰） | `radial-gradient(circle at 33% 29%…)` 19s |
| ⑥ 网点纹理 | 参考图最显眼的**半调点阵** | 明暗两层 `radial-gradient` 点阵（4px / 5px 网格）+ `mix-blend-mode:overlay` |
| ⑦ 暗芯 | 偏心偏右下的柔性黑核 | `radial-gradient(ellipse 19% 22% at 69% 69%…)` + `blur(5px)`，13s |
| ⑧ 边缘球感 | 只压最外一圈 + 左上受光 | 外环压暗 + `box-shadow:inset` 双向受光 |

- 三组色团各按不同周期（17s / 21s / 25s）`ease-in-out` 游移，**任意时刻三种以上颜色同屏且互相过渡**，实现「持续缓慢流动、混合变色」的效果。
- 整球另有 7s 的轻微上下浮动（`.demo-orb-inner`），保持呼吸感。
- `prefers-reduced-motion:reduce` 下关闭全部动画。
- 独立预览页 `_orb-preview.html`（124 / 72 / 40px 三档 + 360px 放大特写）便于单看网点纹理与色彩流动。

**调参记录**：初版整球发黑（暗芯+边缘过重）→ 二版颜色被高光洗灰 → 三版色彩饱和但暗芯过大占半屏 → **本版**收小暗芯（26%→19%）、高光改为角落局部、色团 alpha 提升至接近 1.0，四色同屏且网点清晰，与参考图观感一致。

- 教师视角示例：事务→「各班请假口径是否一致」「相邻两版培养方案差在哪」；学习→「整理讲义提纲」「按 16 周排教学进度表」；实践→「这道题的考点怎么讲」「班级通过率偏低卡在哪」「出一组变式题」；创作→「教研组汇报 10 页」「课程导学幻灯片」。
- 教师身份下不触发课程的「先确认资料范围」澄清流程（教师已掌握课程范围）。
- 条件条的说明文案随身份变化（学生口径 vs 教师口径）。

**输入提示随模式变化**（`PLACEHOLDER`）：探索=查询政策…／学习=问课程内容…／实践=描述题目或粘贴代码／创作=说清用途页数时长。

**验证（CDP）**：`探索模式条件条可见=true · 学习模式条件条隐藏=true · 读秒状态="正在理解你的问题并查找相关资料0.4s" · 已无 .dm-steps/.dm-step · 回答后状态 removed · cites=3 · 教师身份问题集正确切换 · 切身份后 hero 复位 · 教师·学习 sections=4 · 无溢出 · EXCEPTIONS none · 1 个 script block 语法 OK`。

## 技术栈

原生 HTML + CSS + JavaScript 单文件，无框架、无构建工具、无运行时后端依赖；唯一外部资源为白名单内的自托管字体镜像。

图片资源当前经 CDN 引用；图片不可达时页面自动降级为「截图占位说明卡片」，因此即使全部外链失效，页面依然可完整浏览与验收。

「立即试试」交互演示同理：全部逻辑与示例数据内联在页面里，不发起任何网络请求，离线打开也能完整交互。
